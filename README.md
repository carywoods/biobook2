# Bioinformatics textbook Hugo sites

This is the Hugo-based modern UI version of the bioinformatics textbook.

## Directory Structure
- `content/chapters/` - Chapter sections organized by topic
- Each section has:
  - `_index.md` - Section landing page with chapter list
  - Individual `.md` files for each chapter from Quarto

## Conversion Status
Chapters converted from Quarto to Hugo markdown format.
