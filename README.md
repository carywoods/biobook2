# Bioinformatics with AI — Hugo site

The bioinformatics textbook, migrated from Quarto to Hugo using the
[hugo-book](https://github.com/alex-shpak/hugo-book) theme.

## Requirements

- **Hugo extended >= 0.158.0** (the hugo-book theme requires it)

Check yours with `hugo version`. It must say `+extended`.

## Local development

```bash
hugo server
# http://localhost:1313
```

Build the static site:

```bash
hugo --minify --gc     # output lands in public/
```

## Structure

```
content/
  _index.md              landing page
  docs/                  the book (hugo-book renders this as the sidebar menu)
    _index.md            chapter index
    foundations/         Chapter 1
    analysis/            Chapters 2-4
    genomics/            Chapters 5-8
    ai-native/           Chapters 9-14
themes/hugo-book/        theme, vendored (not a submodule)
```

The theme is **vendored** rather than a git submodule so that any build system
(Coolify, CI) gets the theme files from a plain clone with no extra steps.

## Notes on configuration

- `relativeURLs = true` in `hugo.toml` makes the output portable: the same build
  works at a bare domain, a subpath, or an autogenerated hostname. This avoids
  broken CSS/links when the deploy URL differs from a hardcoded `baseURL`.
- `BookSection = "docs"` tells the theme which section to render as the sidebar.
- Callouts use GitHub-style markdown alerts (`> [!TIP]`), which the theme styles.
  The older `{{< hint >}}` shortcode is deprecated upstream.

See `DEPLOY.md` for deployment.
