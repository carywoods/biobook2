# Bioinformatics with AI

A Modern Introduction to Computational Biology and Artificial Intelligence

By Dr. Cary Woods · Envoi Publishing

## About This Book

This book teaches bioinformatics through paired examples: each concept is shown
first as a plain ("vanilla") Python script, then revisited using AI assistance so
you can see how large language models change the way this work gets done.

## How It Is Organized

- **Foundations** (Chapter 1) — the language of life and how biology becomes data
- **Analysis** (Chapters 2-4) — Python basics, the central dogma, biological data
- **Genomics** (Chapters 5-8) — alignment, motifs, expression, protein structure
- **AI-Native** (Chapters 9-14) — genome analysis, metagenomics, single-cell,
  LLM reasoning, pipelines, and capstone projects
